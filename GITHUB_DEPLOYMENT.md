# GitHub Deployment Guide

See GITHUB_DEPLOYMENT.md for instructions on deploying to GitHub Pages.

## Quick Start

1. Create repo: https://github.com/new (name: gittree)
2. Add remote: git remote add origin https://github.com/dongfangzhizhu/gittree.git
3. Push: git push -u origin master
4. Enable Pages in Settings
5. Done - auto-deploys to https://dongfangzhizhu.github.io/gittree/
